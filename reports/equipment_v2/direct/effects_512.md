## 확인한 것

- 선량: 원리대로면 노이즈는 선량의 제곱근에 반비례하므로 선량 1/4, 1/16, 1/64에서 2.00 / 4.00 / 8.00배가 되어야 한다. 실제 사진에서 잰 노이즈 추정은 2.12 / 4.02 / 7.86배다 (기준 노이즈 SIGMA0[512] = 0.622).
- 센서 화소 0.5 / 1.0 / 2.0mm는 512 사진에서 1.1 / 2.3 / 4.6 픽셀이다. 224 사진에서는 0.5 / 1.0 / 2.0 픽셀이라 앞의 둘은 거의 보이지 않았다.
- 평균 밝기를 유지하도록 만든 필터(조사시간·산란·kVp·센서)의 평균 밝기 변화는 절댓값 최대 0.00다 (0~255 기준).
