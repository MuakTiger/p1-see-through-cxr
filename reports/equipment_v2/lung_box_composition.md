# 폐 상자의 구도와 test 정상 recall (해석용, 모델·필터·강도 선택에 쓰지 않음)

생성: `src/lung_box_composition.py`. 폐 마스크는 PSPNet(`runs/lung_masks`, 입력 512 기준), 면적 5% 미만인 분할 실패는 뺐다 (train 4장, val 1장, test 0장). test 는 같은 사진 사본 6장을 뺀 618장. 모델은 B512 seed 42, 재학습 없음, test 는 정상 사진 예측에만 썼다.

## 1. 폐 상자가 사진에서 차지하는 비율 (중앙값)

| 묶음 | 장수 | 세로 점유 | 가로 점유 | 폐 면적 비율 |
|---|---|---|---|---|
| train·val 정상 | 1341 | 0.729 | 0.775 | 0.338 |
| train·val 폐렴 | 3870 | 0.846 | 0.760 | 0.365 |
| test 정상 | 231 | 0.838 | 0.756 | 0.400 |
| test 폐렴 | 387 | 0.861 | 0.762 | 0.366 |

세로 점유 = 폐 마스크의 위아래 끝 사이 길이 ÷ 사진 세로(512). 가로 점유도 같은 방식이다. 사진은 모델 입력과 같이 가로세로를 정사각형으로 눌렀다.

## 2. test 정상 사진의 recall 을 폐 상자 세로 점유 3분위로 나눠 본 값 (B512 seed 42)

| 세로 점유 | 장수 | 점유 중앙값 | 정상으로 맞힌 비율 |
|---|---|---|---|
| 낮음 | 77 | 0.752 | 0.597 |
| 중간 | 77 | 0.838 | 0.468 |
| 높음 | 77 | 0.904 | 0.273 |

- 스피어만 상관 (정상 확률 p_normal 과): 세로 점유 -0.36 (p=1.8e-08), 가로 점유 -0.13 (p=5.4e-02), 폐 면적 -0.17 (p=9.5e-03).
- test 정상 231장 중 정상으로 맞힌 사진 103장 (0.446).

## 읽는 법과 한계

- 폐가 사진 세로를 꽉 채운 정상 사진일수록 모델이 폐렴으로 판정하는 경향이 있다. 이것은 **연관**이며 원인이 아니다. 같은 사진은 다른 특성(저장 방식, 촬영 시기 등)도 함께 다르다.
- train·val 정상은 폐 위아래에 여백이 많고, 폐렴과 test 정상은 폐가 세로를 더 채운다. 강사 의견(폐 영역 상자로 잘라서 구도를 맞추면 달라질 수 있다)과 방향이 맞는 정황이지만, **폐 상자 크롭으로 다시 학습하는 실험은 아직 하지 않았다.**
- 폐 마스크는 사진 12장만 눈으로 확인했고, 폐렴으로 뿌옇게 된 폐는 놓칠 수 있다 (그러면 폐렴 쪽 점유가 작게 나온다).
- 모델 1개(seed 1개), 정상 사진 한 묶음(test 정상)이다.
