# 폐 영역 입력 모델(기준 설정 + 폐 밖 지우기) 계획 (결과를 보기 전에 고정)

작성: 2026-10-22 밤, **폐 영역 모델의 점수를 보기 전**. 결과를 보고 바꾸지 않는다. 바꿔야 하면 새 버전 문서를 만든다. test는 이 문서에서 열지 않는다(결과 뒤 별도 계획 문서와 해시 고정이 필요).

## 1. 질문과 동기

- B512 계열 기준 모델(b)의 Grad-CAM은 폐에 몰리지 않았다. val 1,030장에서 PSPNet 폐 마스크 기준으로 지도 중 폐 안 비율이 0.29~0.35로 폐 면적 비율(0.36) 이하였고, 정답이 정상인 사진은 지도 최고점이 폐 안인 비율이 2~14%였다 (`reports/equipment_v2/gradcam/lung_focus_val.md`). 가리기 시험에서도 지도가 높은 칸을 가리면 판정이 51% 바뀌었다.
- 가설: 모델이 폐 밖(어깨·글자·복부·모서리)의 단서를 쓴다. **폐 밖을 지우고 같은 설정으로 학습하면** (a) 원본 val 성능이 유지되는가, (b) 장비 필터 약점이 달라지는가, (c) 새 집단에서의 성능이 달라지는가(c는 test, 이 문서 밖).
- 설계 근거는 val에서 한 진단과 폐 해부 사전지식뿐이다. **test 결과에서 얻은 가설은 쓰지 않았다.** 다만 이 문서를 쓰는 시점에 B512와 기준·예방접종 모델의 test 결과는 이미 알려져 있었다는 점을 밝힌다.

## 2. 설계 (B512 설정에서 입력만 바꿈)

- 공통(기준 b와 같음): ResNet18 ImageNet 사전학습, layer4 + fc 학습, Adam, 학습률 fc 0.001 / layer4 0.0001, 배치 16, 최대 30에폭, 입력 512, 증강 없음, 클래스 가중치 없음, **에폭 선택 규칙도 같음(폐 처리한 val의 Macro-F1 최고 에폭)**. `training/train_aug.py --augment none`을 그대로 쓴다.
- **입력 처리** (`training/lung_prep.py`, 규칙을 결과 전에 정함): 모든 사진을 평가와 같은 경로(회색 512×512)로 만든 뒤, PSPNet이 만든 좌·우 폐 마스크의 합의 **볼록 껍질**을 구해 16px(512의 약 3%) 넓히고, 그 밖의 화소를 0으로 칠한다. 자르기·확대·크기 변경은 없다(한 번에 한 가지만 바꾼다). 볼록 껍질을 쓰는 이유는 폐렴으로 뿌옇게 된 부위가 마스크에서 빠져도 껍질 안에는 남기고, 두 폐 사이(종격동·심장 그림자)도 남기기 위해서다. 여백 16px은 흉막 가장자리와 분할 오차를 받아 주려고 정했고 결과를 보고 조정하지 않는다.
- **분할 실패 규칙:** 마스크가 사진 면적의 5% 미만이면 분할 실패로 보고 사진 전체를 그대로 쓴다. train·val·test에서 이런 사진의 개수를 보고한다.
- **폐 분할 모델:** TorchXRayVision 1.5.7의 `chestx_det.PSPNet` (공식 GitHub 릴리스 가중치, 512 입력, 14개 구조 중 좌·우 폐, 시그모이드 0.5). 학습 데이터와 소아 사진에서의 정확도는 확인하지 못했다. 소아 val 사진 12장을 눈으로 확인했고(대체로 정확, 폐렴으로 뿌연 부위 누락 1장, 복부로 번짐 1장, 작은 구멍 1장), val 전체에서 폐 면적 평균 35.8%, 면적 5% 미만 1장이었다.
- **마스크는 필터를 걸지 않은 사진에서 한 번만 만들어 고정**하고, 필터 시험에서도 같은 마스크를 쓴다 (라벨은 쓰지 않는다).
- 모델: seed 42·43·44의 3개 (`l-s42`, `l-s43`, `l-s44`). 학습은 SageMaker JupyterLab(ml.g4dn.xlarge)에서, 기준(b-s42·43·44)과 같은 환경이다.

## 3. 평가 (val만, test는 열지 않는다)

`src/equipment_eval_lung.py`(= `equipment_eval_direct.py`와 같은 시험, 필터를 먼저 걸고 그다음 고정 마스크로 폐 처리): 원본과 필터 33조건, 같은 강도, 같은 bootstrap.

- 비교 대상은 같은 환경의 기준 b-s42·43·44 (이미 평가됨, `reports/equipment_v2/vac/val_b-s*`).
- 지표와 판정은 `vaccine_plan.md`와 같은 규칙: ① 원본 val Macro-F1, ② 본편 24조건(새 5종 + 경계 강조·대비 보정·JPEG, 각 3단계) 평균 Macro-F1과 원본 대비 하락, ③ 부록 9조건, ④ 강 조건별 값. 폐 모델 − 기준의 평균 차이가 **기준 3개의 seed 표준편차의 2배 이상**일 때만 "차이 있음", 아니면 "차이를 말할 수 없음". 이 모델은 필터로 학습하지 않았으므로 24조건 모두를 같은 방식으로 본다.
- 6개의 결과를 빠짐없이 보고한다.

## 4. 한계 (결과와 상관없이 적는다)

- **val은 train과 같은 단서를 공유**하므로, 폐 밖을 지워도 val 점수가 변하지 않는 것이 "지름길이 없다"는 뜻은 아니고 반대로 변하는 것이 곧 개선도 아니다. 새 집단에서의 효과는 test(별도 계획)로만 볼 수 있다.
- 폐 안에 남은 처리 흔적(대비·질감), 폐 윤곽의 모양과 크기 자체가 새 단서가 될 수 있다.
- 폐 밖에도 진단 단서(심장 그림자, 흉수, 횡격막 등)가 있어 지우면 정보를 잃을 수 있다.
- 분할 오류(폐렴으로 뿌연 부위 누락, 복부로 번짐)가 입력을 왜곡할 수 있다. 마스크 품질은 12장을 눈으로, 나머지는 통계로만 확인했다.
- 필터 시험의 마스크는 필터를 걸지 않은 사진 기준이다. 실제 시스템은 필터가 걸린 사진에서 분할해야 하므로, **분할 모델 자체의 강건성은 이 시험에 들어 있지 않다.**
- 입력이 폐 처리된 것이라 이 모델을 쓰려면 PSPNet이 항상 앞에 붙어야 한다(두 단계 시스템).
- seed 3개라 작은 차이는 구분하지 못하고, 기준 모델의 에폭 선택 흔들림(b-s43은 에폭 1)이 판정을 엄격하게 만든다. 외부 사전학습 분할 모델의 학습 데이터는 확인하지 못했다.
- test를 열려면 이 결과를 본 뒤에 새 계획 문서를 만들고 해시를 고정한다. 이미 test를 연 적이 있는 데이터에서의 추가 분석임을 밝힌다.
