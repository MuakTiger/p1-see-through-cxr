# 폐 영역 모델 계획 보충 (학습 환경 변경과 기준 추가, 결과를 보기 전에 고정)

작성: 2026-10-22 19시경, **폐 영역 모델과 새 기준 모델의 점수를 보기 전**. `lung_plan.md`(18:45 고정)는 수정하지 않고, 달라진 점만 이 문서에 적는다.

## 1. 달라진 점

- **학습 환경:** 사용자 결정(10/22 저녁)으로 JupyterLab 대신 **SageMaker Training Jobs**(`ml.g4dn.2xlarge`, PyTorch 컨테이너 torch 2.2)에서 여러 개를 동시에 학습한다. `lung_plan.md`는 "기준 b-s42·43·44와 같은 환경"이라고 했으나, 폐 모델(AWS)과 JupyterLab 기준(torch 2.8)의 환경이 달라진다.
- **기준 모델 추가:** 같은 환경의 기준을 3개로 만들기 위해, 이미 있는 AWS B512(seed 42, `b512-20261022-111844`)에 더해 **B512 seed 43, 44**를 같은 설정(`training/train.py`, 증강 없음, 입력 512, layer4 + fc)으로 새로 학습한다.
- **판정:** `lung_plan.md` 3장의 규칙(폐 모델 − 기준의 평균 차이가 기준 3개의 seed 표준편차의 2배 이상일 때만 "차이 있음")을 **두 기준 묶음 각각에 적용해 모두 보고**한다. (가) **주 비교 = 같은 환경의 AWS 기준 3개**(B512 seed 42·43·44), (나) 보조 = JupyterLab 기준 3개(b-s42·43·44). 두 판정이 다르면 그대로 쓰고 환경 차이가 섞였음을 적는다.

## 2. 데이터 준비 (확인한 것)

- 폐 마스크: train 4,186장(폐 면적 평균 35.5%), val 1,030장(35.8%). 학습·val 사진 5,216장을 `src/make_lung_images.py`로 폐 영역 PNG(회색 512×512)로 만들어 S3(학생 prefix의 `lung512/images/`, 매니페스트 `lung512/manifests/`)에 올렸다. 이 사진을 `images` 채널로 읽어 `training/train_aug.py --augment none`으로 학습한다 (학습 코드는 폐 처리를 모르고, 입력만 다르다).
- **분할 실패(마스크 면적 5% 미만)로 사진 전체를 그대로 쓴 사진이 5장(train 4, val 1)이고 전부 세균성이다.** "폐 밖이 지워지지 않은 사진 = 세균성"이 새 단서가 될 수 있으나 세균성 2,530장 중 5장(0.2%)이라 영향이 작다고 보고, 결과를 보고 이 사진을 빼거나 다시 만들지 않는다.
- 제출 도구 `submit_training.py`에 `--images-uri`, `--manifests-uri`, `--manifest-file`(제출 기록의 해시용) 옵션을 더했다. 기본 동작은 그대로다.

## 3. 그대로인 것

- 폐 모델 설정, 입력 처리 규칙, 평가(val만, test는 열지 않음), 한계 목록은 `lung_plan.md` 그대로다. 결과를 보고 바꾸지 않는다.
