# 폐 영역 + 예방접종(lv) 계획 (결과를 보기 전에 고정)

작성: 2026-10-22 19시경, **lv 모델과 폐 영역 모델(l)의 점수를 보기 전**. 결과를 보고 바꾸지 않는다. 바꿔야 하면 새 버전 문서를 만든다. test는 이 문서에서 열지 않는다(val 결과 뒤 별도 계획과 해시 고정이 필요).

## 1. 질문

폐 영역 입력(`lung_plan.md`) 위에서 학습 때 장비 필터를 섞으면(`vaccine_plan.md`의 예방접종) 폐 영역 모델(l)보다 필터 약점이 줄어드는가? 학습에 쓰지 않은 유형(경계 강조·대비 보정·JPEG)에서도 덜 무너지는가?

## 2. 설계

- 입력 처리와 학습 설정은 폐 모델(l)과 같다: ResNet18 ImageNet 사전학습, layer4 + fc, Adam, 학습률 fc 0.001 / layer4 0.0001, 배치 16, 최대 30에폭, 입력 512, 에폭 선택 규칙(폐 처리한 val의 Macro-F1 최고 에폭). 폐 입력은 PSPNet 폐 마스크의 볼록 껍질 + 16px 밖을 0으로, 분할 실패(면적 5% 미만)는 전체 사진 (`training/lung_prep.py`).
- **증강은 `vaccine_plan.md`와 같다:** 학습 사진의 50%에 기기 설정 필터 5종(선량·조사시간·산란·kVp·센서) 중 하나를 고르게, 세기 u ~ Uniform(0, 1) (u=1이 시험의 '강'). val에는 증강을 걸지 않는다.
- **순서는 필터 → 폐 처리**다(평가 `equipment_eval_lung.py`와 같은 순서). 필터는 전체 회색 512 사진에 먼저 걸고 그다음 폐 껍질 밖을 0으로 칠한다. 마스크를 미리 칠한 사진에 필터를 걸면 산란·kVp·대비 보정이 폐 안쪽에서도 달라져(val 60장 점검: 폐 안쪽 차이 8.3 / 16.6 / 22.7, 0~255 기준) 평가와 다른 필터가 되기 때문이다. 그래서 새 학습 코드 `training/train_lung.py`(train_aug.py 복사본 + 폐 입력)를 만들었다. 입력 처리 검증: 학습 입력이 평가 입력과 5종 필터 모두에서 완전히 같고(최대 차이 0.0), 폐 영역 PNG(l 모델의 입력)와도 같다.
- 껍질 마스크는 `runs/lung_masks/lung_hull_masks.npz`(train+val 5,216장, 분할 실패 5장은 전체 사진)이고 S3 weights 폴더에 올려 학습 작업이 읽는다. 사진은 원본(`source_s3`)을 그대로 읽는다.
- 모델: seed 42·43·44 (`lv-s42`, `lv-s43`, `lv-s44`), AWS Training Jobs(`ml.g4dn.2xlarge`, torch 2.2), 폐 모델 l과 같은 환경이다.

## 3. 평가 (val만, test는 열지 않는다)

`src/equipment_eval_lung.py`로 원본과 필터 33조건을 잰다(폐 모델과 같은 시험).

- **주 비교 = 폐 영역 모델 l-s42·43·44** (같은 환경, 같은 입력 처리, 증강만 다름). 판정은 `vaccine_plan.md`와 같은 규칙: 지표별로 lv − l의 평균 차이가 **l 3개의 seed 표준편차(ddof=1)의 2배 이상**일 때만 "차이 있음", 아니면 "차이를 말할 수 없음".
- 지표: ① 원본 val Macro-F1(원본 성능 손실이 없는지), ② 학습에 쓴 5종 15조건 평균, ③ **학습에 쓰지 않은 3종 9조건 평균**(방어력을 보는 부분), ④ 부록 9조건, ⑤ 강 조건별 값. 학습에 쓴 5종은 배운 유형이라 방어력의 증거로 쓰지 않는다.
- 참고 비교: 일반 예방접종 v(JupyterLab 3개)와 AWS 기준 B512 3개. 6개의 결과를 빠짐없이 보고한다.

## 4. 한계 (결과와 상관없이 적는다)

- `lung_plan.md`의 한계를 모두 따른다(val은 같은 단서를 공유, 폐 안 흔적·윤곽 모양이 단서일 수 있음, 폐 밖 진단 단서 손실, 두 단계 시스템, 필터 시험의 마스크는 필터 없는 사진 기준).
- **폐 분할은 병이 심한 쪽에서 틀린다.** 분할 실패 5장은 모두 세균성이고(폐가 하얗게 꽉 찬 사진), 마스크가 쪼개진 사진(솔리디티 0.5 미만)은 세균성 2.7%, 바이러스성 1.3%, 정상 0%이다(`reports/equipment_v2/lung_model/seg_failures_rule.png`, `seg_suspects.png`). 이런 사진에서는 병변이 있는 쪽이 껍질 밖으로 잘려 나갈 수 있다.
- 학습 세기의 상한이 '강'이라 그 안쪽만 본다. 학습에 쓰지 않은 유형이 완전히 낯선 것은 아니다(`vaccine_plan.md`와 같음).
- seed 3개라 작은 차이를 구분하지 못하고, 표준편차 추정이 거칠다.
- 이 실험 뒤에 test를 열면 새 계획 문서를 만들고, 이미 test를 열었던 데이터에서의 추가 분석임과 설계에 test를 참고했는지를 밝힌다.
