# 과적합 줄이기 실험 계획 (결과를 보기 전에 고정)

작성: 2026-10-22 오후, **아래 5가지 설정의 새 점수를 보기 전**. 결과를 보고 바꾸지 않는다. 바꿔야 하면 새 버전 문서를 만든다.

## 1. 왜 하나

B512 학습 기록: 학습 손실은 10에폭쯤 0.02, 30에폭에 0.007로 학습 사진을 거의 외우고, val 손실은 1에폭에서 최저(0.39)였다가 30에폭에 1.04까지 올랐다(확신만 커짐). val F1은 30에폭 내내 0.77~0.84에서 출렁이고(평균 0.814) 우리가 고른 0.843은 그중 최댓값이다. 224 모델 8개와 B512를 합쳐 보면 val F1이 높을수록 test F1이 낮은 경향이 있었다(상관 −0.64, 표본 9개, 단일 seed). 특징을 고정한 A는 과적합이 없었고 val→test 낙폭이 가장 작았다(−0.058). 이것이 과적합 때문인지는 모른다. 이 실험은 과적합을 줄이는 일반적인 방법들이 필터 약점과 과신에 어떤 영향을 주는지 본다.

## 2. 설정 5가지 (B512에서 한 가지씩만 바꿈, 나머지는 B512와 같음)

공통: ResNet18 ImageNet 사전학습, 입력 512, layer4 + fc 학습(r4만 fc), Adam(r3만 AdamW), 학습률 fc 0.001 / layer4 0.0001, 배치 16, 증강·전처리 없음, 클래스 가중치 없음, 시드 42·43·44.
**모든 설정에서 val 최댓값으로 에폭을 고르지 않고 마지막 에폭의 모델을 쓴다** (`--select last`).

| 이름 | 바꾼 것 |
|---|---|
| r0 | 바꾼 것 없음 (30에폭, 마지막 에폭). B512를 마지막 에폭 방식으로 다시 학습한 기준 |
| r1 | 에폭을 5로 줄임 |
| r2 | 학습 손실에 라벨 스무딩 0.1 (val 손실은 그대로) |
| r3 | AdamW, 가중치 감쇠 0.1 |
| r4 | 특징 고정 (fc만 학습, A의 512판) |

가중치 감쇠 0.1, 라벨 스무딩 0.1, 에폭 5는 값을 탐색하지 않고 미리 하나씩만 정했다.

## 3. 평가와 선택 기준 (val만, test는 열지 않는다)

- 원본 val Macro-F1 (마지막 에폭), 에폭 중 최댓값(참고용, 선택에 쓰지 않음).
- 필터 24조건(새 5종 + 경계 강조·대비 보정·JPEG, 각 3단계) 평균 Macro-F1: `src/equipment_eval_direct.py`와 같은 시험, 같은 강도.
- 과신: 마지막 에폭 val 예측에서 val 손실(가중치·스무딩 없는 CrossEntropy), 틀린 예측 중 최대 확률이 0.9 이상인 비율.
- 선택: **(원본 val F1 + 필터 24조건 평균 F1) / 2**를 seed 3개 평균으로 비교한다. 설정 간 차이가 seed 표준편차(같은 설정의 3개 seed)보다 작으면 "차이를 말할 수 없다"로 쓰고, 그 경우 B와 가장 가까운 설정(r0)을 유지한다.
- 모든 설정의 결과를 빠짐없이 보고한다 (좋은 것만 고르지 않는다).

## 4. 한계 (결과와 상관없이 적는다)

- val에서 고른 설정이 test에서도 낫다는 보장은 없다. 지금까지 val과 test의 순위가 반대였다.
- seed 3개로 작은 차이는 구분하지 못한다.
- 과적합이 test 낙폭의 원인이라는 증거는 아직 없고, 이 실험은 인과를 증명하지 않는다.
- test는 이 실험의 선택에 쓰지 않는다. 이후 test를 열면 계획 문서를 새로 만든다.
