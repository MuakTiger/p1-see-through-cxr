# 장치 설정 필터 v2: 강도 고정 문서 (val 시험 전)

작성: 2026-10-22 11:02, **모델 점수를 보기 전**. 이 문서는 val 시험을 돌리기 전에 쓰며, 시험 결과를 보고 고치지 않는다. 바꿔야 하면 새 버전 문서를 따로 만든다.

## 1. 시험 전에 본 것과 못 본 것

- 본 것: 필터를 건 사진(`gallery_new.png`, `feel.png`, `zoom.png`), 사진에서 잰 물리량(`effects.md`: 밝기·대비·경계 세기·노이즈 추정).
- 못 본 것: 새 필터 5종에 대한 모델 점수. (v1에서 그대로 쓰는 6종의 B 점수는 `reports/shift_test`에 이미 있다.)
- 강도는 사용자가 사진을 보고 정했다: 선량 1/4·1/16·1/64, kVp 강 (0.60, 0.5). 나머지는 처음 임시값 그대로.

## 2. 필터와 강도 (약 / 중 / 강)

새로 만든 5종 (`training/equipment_filters.py`, 896×896 작업 해상도에서 걸고 모델이 보는 224 원본에 변화량만 더함):

| 필터 | 장치 원리 | 강도 | 구현 |
|---|---|---|---|
| 선량 (mAs) | 선량이 줄면 광자가 줄어 양자 노이즈가 늘어난다 (노이즈 ∝ 1/√선량) | 상대 선량 1/4 / 1/16 / 1/64 | 노출량 (1-밝기)에 밝기 비례 노이즈. 기준 노이즈는 원본 224의 노이즈 추정 약 0.9 |
| 조사시간 (움직임) | 오래 찍으면 아이가 움직여 세로로 번진다 | 번짐 길이 2 / 4 / 8mm (224에서 1픽셀 ≈ 1mm) | 세로 방향 상자 필터, 위 25% ~ 아래 100%로 세기가 늘어남 |
| 산란 (격자 없음) | 산란선이 안개처럼 깔려 작은 구조의 대비가 줄어든다 | 산란/직접선 비 k = 0.25 / 0.5 / 1.0 | (원본 + k × 아주 크게 흐린 사진) / (1 + k), 흐림 폭 25mm |
| 관전압 kVp ↑ | 대비가 줄고 밝은 부위(뼈)가 덜 하얘진다 | (대비 배율, 밝은 쪽 기울기) = (0.85, 0.8) / (0.70, 0.6) / (0.60, 0.5), 눌러 주기 시작 0.6 | 평균 기준 대비 축소, 0.6 위 기울기 축소, 평균 밝기는 원본과 같게 |
| 센서 화소 크기 | 화소가 커지면 미세한 무늬가 뭉개진다 | 화소 0.45 / 0.9 / 1.8mm (화소 평균 2 / 4 / 8배) | 화소 평균으로 줄였다가 다시 키움 |

v1에서 그대로 쓰는 6종 (`training/shift_filters.py`, 224에 적용, 강도 변경 없음): 흐림 σ 0.5 / 1.0 / 2.0, 경계 강조 α 0.5 / 1.0 / 2.0, 대비 보정 CLAHE 1.5 / CLAHE 3.0 / HE, JPEG 품질 75 / 40 / 20, 밝게 감마 0.85 / 0.7 / 0.55, 어둡게 감마 1.2 / 1.45 / 1.8.

v1의 가우시안 노이즈와 대비 감소는 새 선량과 kVp가 대신하며, v1 결과 파일은 그대로 둔다.

## 3. 시험 방법

- 모델: 실험 B (`runs/results/b-20261019-103853/model`, 증강·전처리 없음, 재학습 없음).
- 데이터: val 1,030장만 (정상/세균성/바이러스성 환자 묶음 단위 분할 그대로). train·check·test는 열지 않는다.
- 필터는 메모리에서만 적용하고 저장하지 않는다. 노이즈 seed는 42 + 사진 번호 (v1과 같음).
- 지표: Macro-F1, AUROC, 클래스별 recall, 원본 대비 변화, 환자 묶음 단위 짝지은 bootstrap 1,000번의 95% 구간, 예측이 바뀐 사진 비율, 예측 분포.
- 검증: (a) 학습과 같은 변환 경로의 원본 Macro-F1이 학습 기록의 베스트 val Macro-F1과 같은지, (b) v1에서 그대로 쓰는 6종을 같은 경로로 다시 돌려 `reports/shift_test`의 B 결과와 같은지, (c) 같은 입력·seed에서 같은 출력이 나오는지, (d) 필터 0단계가 원본과 정확히 같은지.

## 4. 한계 (결과와 상관없이 발표에 적는다)

- 8비트 JPEG라 실제 톤 곡선과 원본 신호를 모른다. 표시 값이 노출량과 선형이라고 가정했다.
- 노이즈 기준은 원본 노이즈 추정에 맞춘 값으로, JPEG와 질감이 섞여 순수한 양자 노이즈가 아니다.
- kVp는 뼈와 연부조직의 에너지 의존 대비를 만들지 못하고 전체 대비 감소와 밝은 쪽 눌러 주기로 근사했다.
- 센서 화소 0.9mm는 224 사진의 1픽셀과 같다. 224 입력에서는 센서 차이가 가려진다.
- 조사시간 번짐 길이, 산란 비율은 실측값이 아닌 설정이다. 이동 속도 등은 문헌으로 확인하지 않았다.
- B는 seed 1개. 점수 변화가 의미 있는지는 구간과 seed 흔들림(D 기준 val 0.818~0.834)을 함께 본다.
- 제조사 후처리(경계 강조, CLAHE/HE)는 실제 알고리즘이 아니라 대표 기법으로 대신한 것이다.
