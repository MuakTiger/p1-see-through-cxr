# 장치 설정 필터 v2.1 (입력 512): 강도 고정 문서 (val 시험 전)

작성: 2026-10-22 12:3x, **B512 모델의 새 필터 점수를 보기 전**. 시험 결과를 보고 고치지 않는다. 바꿔야 하면 새 버전 문서를 따로 만든다.
224판 문서는 `strength_fixed.md` (그대로 유지, 결과는 `val_B/`).

## 1. 왜 512인가

강사 의견: 224로 줄이면 필터 효과가 뭉개진다. 224판 시험에서도 센서 0.45·0.9mm가 점수 변화 0이었고 선량 1/4는 구간이 0을 포함했다.
448(= 224×2)은 지난번에 이미 해 본 실험(B448)이다. 1024는 원본 사진 크기가 클래스마다 달라(짧은 변 중앙값 정상 1,323 / 세균성 752 / 바이러스성 824,
1024 미만 비율 11% / 84% / 74%) 폐렴 사진 대부분이 확대되는 반면 정상은 축소되어, 늘린 정도(선명도)가 클래스 단서가 될 위험이 있어 쓰지 않는다.
512 미만 사진은 0.1% / 6.8% / 6.4%이다.

## 2. 224판과 달라진 것 (점수를 보고 바꾼 것은 없다)

- 필터를 224 사진이 아니라 모델이 보는 512×512 회색조(`shift_filters.to_gray(im, 512)`)에 직접 건다 (`training/equipment_direct.py`). 224판은 896에서 걸고 줄였다.
- 길이 단위: 224 사진에서 1픽셀 ≈ 1mm로 놓고, 512 사진에서는 1mm = 512/224 = 2.29픽셀. 224판에서 센서 라벨(0.45 / 0.9 / 1.8)은 가슴 폭 20cm 가정, 번짐·산란은 1픽셀 = 1mm 가정이라 서로 달랐다. 512판은 한 가지로 통일했고, 센서 화소의 라벨만 0.5 / 1.0 / 2.0mm로 정리했다 (512에서 1.1 / 2.3 / 4.6픽셀).
- 선량의 기준 노이즈: 512 원본 val 200장의 노이즈 추정 평균 0.699에 보정계수 0.890을 곱한 0.622. 선량 1/16에서 노이즈 추정 배율이 원리값 4.0이 되도록 맞췄다 (`src/noise_anchor.py --calibrate`). 모델 점수는 쓰지 않았다. 보정 후 확인: 선량 1/4·1/16·1/64에서 2.12 / 4.02 / 7.86배 (원리값 2 / 4 / 8).
- 나머지 강도와 구현(조사시간, 산란, kVp)은 224판과 같다.
- 이 문서는 B(224)에서 33조건의 점수를 이미 본 뒤에 썼다. 그래서 "점수를 보기 전에 정한 강도"가 아니라 "224판 강도를 그대로 가져오고 단위만 정리한 것"이다.

## 3. 필터와 강도 (약 / 중 / 강)

새로 만든 5종:

| 필터 | 장치 원리 | 강도 | 구현 (512 사진에서) |
|---|---|---|---|
| 선량 (mAs) | 선량이 줄면 광자가 줄어 양자 노이즈가 늘어난다 (노이즈 ∝ 1/√선량) | 상대 선량 1/4 / 1/16 / 1/64 | 노출량 (1-밝기)에 밝기 비례 노이즈, 기준 노이즈 0.622 (0~255) |
| 조사시간 (움직임) | 오래 찍으면 아이가 움직여 세로로 번진다 | 번짐 길이 2 / 4 / 8mm (= 5 / 9 / 19픽셀) | 세로 방향 상자 필터, 위 25% ~ 아래 100% |
| 산란 (격자 없음) | 산란선이 안개처럼 깔려 작은 구조의 대비가 줄어든다 | k = 0.25 / 0.5 / 1.0, 폭 25mm (= 57픽셀) | (원본 + k × 크게 흐린 사진) / (1 + k) |
| 관전압 kVp ↑ | 대비가 줄고 밝은 부위(뼈)가 덜 하얘진다 | (대비 배율, 밝은 쪽 기울기) = (0.85, 0.8) / (0.70, 0.6) / (0.60, 0.5), 눌러 주기 시작 0.6 | 평균 기준 대비 축소, 0.6 위 기울기 축소, 평균 밝기는 원본과 같게 |
| 센서 화소 크기 | 화소가 커지면 미세한 무늬가 뭉개진다 | 화소 0.5 / 1.0 / 2.0mm (= 1.1 / 2.3 / 4.6픽셀) | 화소 안에서 평균(줄이기) 후 다시 키움 |

v1에서 그대로 쓰는 6종 (`training/shift_filters.py`, 512 사진에 적용, 강도 변경 없음; 흐림 σ와 경계 강조의 σ는 크기에 비례해 키움 = 같은 mm): 흐림 σ 0.5 / 1.0 / 2.0, 경계 강조 α 0.5 / 1.0 / 2.0, 대비 보정 CLAHE 1.5 / CLAHE 3.0 / HE, JPEG 품질 75 / 40 / 20, 밝게 감마 0.85 / 0.7 / 0.55, 어둡게 감마 1.2 / 1.45 / 1.8.

## 4. 시험 방법

- 모델: B512 (`runs/results/b512-20261022-111844/model`, 증강·전처리 없음, 입력 512, 학습 기록의 베스트 val Macro-F1 0.8430, 재학습 없음).
- 데이터: val 1,030장만. train·check·test는 열지 않는다. 필터는 메모리에서만 적용, 노이즈 seed는 42 + 사진 번호.
- 지표: Macro-F1, AUROC, 클래스별 recall, 원본 대비 변화, 환자 묶음 단위 짝지은 bootstrap 1,000번의 95% 구간, 예측이 바뀐 사진 비율, 예측 분포.
- 검증: (a) 학습과 같은 변환 경로의 원본 Macro-F1이 학습 기록의 베스트와 같은지, (c) 같은 입력·seed → 같은 출력, (d) 필터 0단계 = 원본, (e) 코드 해시가 `code_sha256_before_val_direct.txt`와 같은지.
- 파이프라인 회귀 검증: 원래는 B448에 같은 스크립트를 돌려 v1 6종의 점수를 `reports/shift_test_B448`의 기존 결과와 비교하려 했으나, **사용자 지시로 B448 시험은 하지 않는다** (시험 시작 직후 취소, 2026-10-22 오후; 점수는 보지 못했고 강도·방법은 바뀌지 않았다). 대신 v1 6종은 `shift_eval.py`와 같은 호출(`apply_shift(회색조, 필터, 단계, seed=42+사진 번호)`, 회색조는 `to_gray(im, 512)`)을 쓴다는 코드상의 동일성으로 갈음하며, 512에서 직접 재현한 기존 결과는 없다.

## 5. 한계 (결과와 상관없이 발표에 적는다)

- 8비트 JPEG라 실제 톤 곡선과 원본 신호를 모른다. 표시 값이 노출량과 선형이라고 가정했다.
- 노이즈 기준은 원본 사진의 노이즈 추정에 맞춘 값으로, JPEG와 질감이 섞여 순수한 양자 노이즈가 아니다. 노이즈 추정기의 반응이 크기마다 달라 보정계수를 썼다.
- kVp는 뼈와 연부조직의 에너지 의존 대비를 만들지 못하고 전체 대비 감소와 밝은 쪽 눌러 주기로 근사했다.
- 조사시간 번짐 길이와 산란 비율은 실측값이 아닌 설정이다. 이동 속도 등은 문헌으로 확인하지 않았다.
- 센서 화소는 입력 1픽셀보다 작은 값(512에서 0.39mm 미만)은 만들 수 없다.
- 512에서도 원본 사진의 5%는 짧은 변이 512 미만이라 확대된다. 입력 크기가 클래스 단서가 되는지는 확인하지 않았다.
- B512는 seed 1개. 점수 변화가 의미 있는지는 구간과 seed 흔들림(D 기준 val 0.818~0.834)을 함께 본다.
- 제조사 후처리(경계 강조, CLAHE/HE)는 실제 알고리즘이 아니라 대표 기법으로 대신한 것이다.

코드 해시: `code_sha256_before_val_direct.txt`.

## 정정 (2026-10-22 오후, 시험 후에 덧붙임)

5장의 "입력 1픽셀보다 작은 값(512에서 0.39mm 미만)은 만들 수 없다"에서 0.39mm는 가슴 폭 200mm를 가정한 값이다. 이 문서 2장의 규약(224 사진에서 1픽셀 ≈ 1mm, 512에서 1mm = 2.29픽셀)으로 계산하면 입력 1픽셀은 약 0.44mm다. 센서 화소를 만들 수 있는 최소 크기의 설명만 바뀌고, 필터·강도·시험 방법은 바뀌지 않았다.
