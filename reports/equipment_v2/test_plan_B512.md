# B512 test 평가 사전 계획 (원본 성능 + 장치 설정 필터 시험)

작성: 2026-10-22 오후, **B512의 test 점수를 보기 전**. 이 문서와 코드·모델의 해시를 `test_plan_B512.sha256`에 고정한 뒤 test를 한 번만 연다. 기존 `reports/test_eval/evaluation_plan.md`(D 최종, 224)는 수정하지 않는다.

## 1. 알려 둘 것 (사후 결정)

- test 624장은 10/19에 사전 계획에 따라 D(224)를 포함한 8개 모델로 이미 한 번 평가했다. 그 계획의 최종 모델은 D(224)였다.
- 10/22에 연구 질문을 "증강 없이 학습한 기본 모델이 장비 차이에 얼마나 약한가"로 정하고 기준 모델을 B 계열로 바꿨다. 강사 의견으로 입력을 512로 바꿔 B512를 새로 학습했다. 이 결정은 test를 본 뒤에 내려졌고, 기준 모델을 바꾼 이유는 연구 질문이지 test 점수가 아니다. 224 모델의 test 점수(B 0.719, D 0.692)는 이 선택에 쓰지 않았다.
- B512의 설계·강도·에폭 선택은 모두 val 결과로 했다. **B512의 test 점수는 이번이 처음이다.**
- 이 평가는 "사전 지정 추가 분석"이다. 가이드가 test의 추가 사용을 허용하는지는 강사 확인을 권한다 (가이드 본문은 "테스트 점수를 보고 설정을 계속 고르지 않는다"이고 "한 번만"이라는 문장은 찾지 못했다).

## 2. 평가 대상

- 모델: B512 (`runs/results/b512-20261022-111844/model`, 증강·전처리 없음, 입력 512×512, layer4 미세조정, seed 42, 선택 에폭 18, val Macro-F1 0.8430). **이 모델 하나만** 평가한다. 다른 모델(예방접종 모델 등)은 각자 별도의 사전 계획으로 평가한다.
- 데이터: test 624장 중 같은 사진(sha256)이 두 번 들어 있는 6쌍의 사본을 뺀 **618장** (정상 231 / 세균성 240 / 바이러스성 147, 환자 묶음 426). 기존 평가와 같은 규칙(같은 sha256 묶음에서 relative_path 사전순 첫 파일만 남김)이다.

## 3. 평가 내용

1. **원본 성능:** Macro-F1과 95% 구간(환자 묶음 단위 bootstrap 1,000번), Macro-AUROC, 클래스별 recall, 혼동행렬.
2. **장치 설정 필터 시험:** `strength_fixed_512.md`와 같은 33조건(새 5종 + v1 6종 × 3단계, 같은 강도, 노이즈 seed = 42 + 사진 번호)을 test 사진에 걸어 원본 test 대비 Macro-F1 변화와 95% 구간(짝지은 bootstrap)을 잰다. 33조건 **전부 실행하고 전부 보고한다.**
3. 발표 본편에는 8종(새 5종 + 경계 강조, 대비 보정, JPEG)만 쓰고, v1의 흐림·밝게·어둡게 3종은 "처음에 일반 전처리로 정한 것이라 장비 원인과 연결이 약하다"는 이유로 본편에서 빼고 부록에 둔다. 이 구분은 test 결과를 보기 전에 정했고 결과로 바꾸지 않는다.

## 4. 규칙

- 이 문서와 해시를 고정한 뒤 한 번만 실행한다. 결과가 어떻든 모델·필터·강도·방법을 바꾸지 않는다. 결과 파일이 만들어지지 않은 코드 오류가 났을 때만 재실행하고 이유를 기록한다.
- test 점수를 보고 설정이나 모델을 고르지 않는다.
- 계산 장치는 노트북 GPU(mps)다. val에서 AWS GPU와 34행 모두 같은 결과를 확인했다.
- 스크립트는 이 문서의 sha256을 받아야만 test를 연다 (`--plan-file`, `--plan-sha256`).

## 5. 해석할 때 미리 적어 두는 한계

- test 정상 사진은 저장 화질(약 75 vs 96)과 가로세로 비율(1.35 vs 1.22)이 train·val과 달라서, 224 모델에서도 val 점수보다 test 점수가 낮았다(B 0.818 → 0.719). 절대 점수보다 **원본 test 대비 변화**를 중심으로 해석한다.
- seed 1개, 한 병원 데이터, 필터는 실제 장비가 아닌 흉내, test 세균성 환자 77명뿐이다.
- 필터끼리 강도가 보정되지 않아 점수 하락을 직접 비교하면 안 된다.
- 필터 시험은 이미 처리된 8비트 JPEG 사진에 걸었다 (한계 목록은 `strength_fixed_512.md` 5장).
