# 폐 영역 모델 test 평가 사전 계획 (원본 성능 + 장치 설정 필터 시험)

작성: 2026-10-22 19시경, **폐 영역 모델(l-s42·43·44)과 새 기준(B512 seed 43·44)의 점수를 보기 전**. 이 문서와 코드·마스크·모델의 해시를 `test_plan_lung.sha256`에 고정한 뒤 모델마다 test를 한 번씩만 연다. `lung_plan.md`, `lung_plan_note.md`, `test_plan_vaccine.md`는 수정하지 않는다.

## 1. 알려 둘 것

- test 624장은 이미 224 모델들, B512(AWS seed 42), 예방접종·기준 6개로 평가했다. **이번 평가는 "이미 열린 test에서의 사전 지정 추가 분석"이다.** 가이드가 추가 사용을 허용하는지는 강사 확인을 권한다.
- **폐 영역 설계(폐 볼록 껍질 + 16px 밖을 0으로, 설정 그대로)를 정할 때 B512와 기준·예방접종 모델의 test 결과는 이미 알려져 있었다.** 설계 근거는 val에서 한 Grad-CAM·폐 마스크 진단(`gradcam/lung_focus_val.md`)과 폐 해부 사전지식이고, test에서 얻은 가설은 쓰지 않았다고 `lung_plan.md`에 결과 전에 적었다. 그러나 test 결과를 알고 있던 사람의 판단이 완전히 독립이었다는 것은 증명할 수 없다.
- 폐 모델은 AWS Training Jobs(torch 2.2)에서 학습했고 기준 b-s42·43·44는 JupyterLab(torch 2.8)에서 학습했다. 환경 차이를 줄이려고 같은 AWS 환경의 기준 B512 seed 43·44를 새로 학습했다(`lung_plan_note.md`).

## 2. 평가 대상

- 폐 영역 모델 3개: `l-s42`, `l-s43`, `l-s44`.
- **같은 환경(AWS) 기준 3개:** B512 seed 42(기존, `reports/equipment_v2/test_B512`의 결과를 그대로 쓴다), `b512-s43`, `b512-s44`(새로 평가).
- JupyterLab 기준 3개(b-s42·43·44)는 이미 평가한 결과(`reports/equipment_v2/vac/test_b-s*`)를 그대로 쓴다.
- 어떤 모델도 val·test 점수를 보고 빼거나 고르지 않는다. 모델 파일 해시는 평가 직전에 `test_plan_lung.sha256`에 덧붙인다(모델이 아직 없어서 지금 고정할 수 없다).
- 데이터: test 624장 중 같은 사진(sha256) 6쌍의 사본을 뺀 **618장**(정상 231 / 세균성 240 / 바이러스성 147), 규칙은 이전 test 평가와 같다.

## 3. 평가 내용

1. **원본 성능:** Macro-F1과 95% 구간(환자 묶음 단위 bootstrap 1,000번), Macro-AUROC, 클래스별 recall, 혼동행렬.
2. **필터 시험:** `strength_fixed_512.md`와 같은 33조건(같은 강도, 노이즈 seed = 42 + 사진 번호)을 건 사진의 원본 test 대비 Macro-F1 변화. **33조건 전부 실행·보고한다.**
3. **폐 모델의 입력 처리:** `src/equipment_eval_lung.py`(= `equipment_eval_direct.py` + 입력 처리). 순서는 **필터를 전체 회색 512 사진에 먼저 걸고, 그다음 필터를 걸지 않은 사진에서 만든 고정 폐 마스크의 볼록 껍질(16px 여백) 밖을 0으로** 칠한 뒤 모델에 넣는다(물리 효과는 촬영 때 전체 사진에 생기고 분할은 그 뒤라는 순서이고, 기준 모델과 똑같이 필터가 걸린 사진에 마지막으로 마스크만 다르게 적용해 비교하기 위해서다). 이 순서와 `lung_prep.py`의 규칙(볼록 껍질, 16px, 면적 5% 미만이면 분할 실패로 전체 사진 사용)을 결과로 바꾸지 않는다.
4. **폐 마스크(test):** TorchXRayVision PSPNet, 필터 없는 test 사진 624장에서 한 번 생성(라벨 미사용, 학습·val과 같은 방식). 분할 실패(면적 5% 미만) 개수를 보고한다.
5. **요약·판정** (`lung_plan.md` 3장과 같은 규칙): 폐 모델 − 기준의 평균 차이가 **기준 3개의 seed 표준편차의 2배 이상**일 때만 "차이 있음", 아니면 "차이를 말할 수 없음". 지표는 ① 원본 test F1, ② 정상 recall, ③ 본편 24조건(새 5종 + 경계 강조·대비 보정·JPEG, 각 3단계) 평균 Macro-F1과 원본 대비 하락, ④ 부록 9조건, ⑤ 강 조건별 값. **(가) 주 비교 = 같은 환경 AWS 기준 3개**, (나) 보조 = JupyterLab 기준 3개. 두 판정이 다르면 그대로 쓰고 환경 차이가 섞였음을 적는다. val과 test를 같은 표로 나란히 적는다.
6. 6개가 못 되거나 실패한 모델이 있으면 있는 것만 보고하고, seed가 3개 미만인 묶음은 판정 규칙을 쓰지 않고 "참고 수준"으로 적는다.

## 4. 규칙

- 모델마다 해시를 고정한 뒤 한 번만 실행한다. 결과가 어떻든 모델·필터·강도·입력 처리·판정 규칙을 바꾸지 않는다. 결과 파일이 만들어지지 않은 코드 오류가 났을 때만 재실행하고 이유를 기록한다.
- test 점수를 보고 설정이나 모델을 고르지 않는다.
- 계산 장치는 노트북 GPU(mps)다. 스크립트는 이 문서의 sha256을 받아야만 test를 연다(`--plan-file`, `--plan-sha256`).

## 5. 해석할 때 미리 적어 두는 한계

- 폐 모델의 필터 시험은 **분할이 항상 맞다는 가정**(필터를 걸지 않은 사진에서 만든 고정 마스크)에서의 분류기 강건성이다. 필터가 걸린 사진에서 분할 모델이 얼마나 버티는지는 보지 않았다. 실제 시스템은 두 단계라 분할 오류가 그대로 전달된다.
- 분할 실패로 전체 사진을 쓴 사진은 train·val에서 5장이고 모두 세균성이다. test에서는 어느 클래스인지 결과 파일에서 보고한다.
- test 정상은 저장 화질·가로세로 비율이 train·val과 달라 지금까지 모든 모델에서 val보다 낮았다. 폐 밖을 지워도 폐 안의 처리 흔적과 폐 윤곽의 모양은 남아 단서가 될 수 있다.
- seed 3개라 작은 차이를 구분하지 못한다. 기준 모델의 test 원본 F1은 seed마다 0.07 이상 흔들렸다(JupyterLab 기준 0.679~0.760).
- 폐 모델·기준 모두 한 병원 데이터, 필터는 실제 장비가 아닌 흉내, 필터끼리 강도가 보정되지 않았다.
