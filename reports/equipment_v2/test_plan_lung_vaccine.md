# 폐 영역 + 예방접종(lv) 모델 test 평가 사전 계획

작성: 2026-10-22 19시경, **lv 모델과 폐 영역 모델(l)의 점수를 보기 전**. 이 문서와 코드·마스크·모델의 해시를 `test_plan_lung_vaccine.sha256`에 고정한 뒤 모델마다 test를 한 번씩만 연다. `test_plan_lung.md`, `lung_vaccine_plan.md` 등 이전 문서는 수정하지 않는다. test 평가는 val 결과를 보고 열지 말지 정하지 않고 이 문서로 미리 정한다.

## 1. 알려 둘 것

- `test_plan_lung.md` 1장의 내용을 그대로 따른다: test 624장은 이미 여러 번 열렸고, 이번 평가는 "이미 열린 test에서의 사전 지정 추가 분석"이며, 폐 영역·예방접종 설계 당시 B512와 기준·예방접종 모델의 test 결과를 알고 있었다. 설계 근거는 val 진단과 물리 사전지식이다(`lung_plan.md`, `lung_vaccine_plan.md`).
- lv의 증강 필터와 시험 필터는 같은 코드이고, 학습 입력이 평가 입력과 같음(필터 5종 모두 최대 차이 0.0)을 확인했다.

## 2. 평가 대상

- `lv-s42`, `lv-s43`, `lv-s44` (모델 해시는 평가 직전에 `test_plan_lung_vaccine.sha256`에 덧붙인다).
- 비교용 결과는 이미 평가한 것을 그대로 쓴다: 폐 영역 모델 l-s42·43·44(`test_plan_lung.md`에 따른 `reports/equipment_v2/lung/test_l-s*`), AWS 기준 B512 3개, JupyterLab 기준 b·예방접종 v 각 3개.
- 데이터: test 624장 중 같은 사진(sha256) 6쌍의 사본을 뺀 618장(정상 231 / 세균성 240 / 바이러스성 147).

## 3. 평가 내용과 판정

- `test_plan_lung.md` 3장과 같다: 원본 성능(Macro-F1 + 환자 묶음 bootstrap 95% 구간, AUROC, 클래스별 recall, 혼동행렬)과 33조건 전부, 폐 모델과 같은 입력 처리(`src/equipment_eval_lung.py`: 필터를 전체 회색 512 사진에 먼저 걸고 필터 없는 사진에서 만든 고정 폐 마스크의 볼록 껍질(16px) 밖을 0으로).
- **판정:** `lung_vaccine_plan.md` 3장과 같다. **주 비교 = 폐 영역 모델 l 3개**(같은 입력 처리, 증강만 다름), lv − l의 평균 차이가 l 3개의 seed 표준편차(ddof=1)의 2배 이상일 때만 "차이 있음". 지표: 원본 F1, 정상 recall, 학습에 쓴 5종 평균, **학습에 쓰지 않은 3종 평균**(방어력), 부록 9조건, 강 조건별 값. 학습에 쓴 5종은 배운 유형이라 방어력의 증거로 쓰지 않는다. val과 test를 같은 표로 나란히 적는다.
- 3개가 못 되면 있는 것만 보고하고 판정 규칙을 쓰지 않는다(참고 수준).

## 4. 규칙

- 모델마다 해시 고정 뒤 한 번만 실행, 결과로 모델·필터·강도·입력 처리·판정 규칙을 바꾸지 않는다. 결과 파일이 만들어지지 않은 코드 오류가 났을 때만 재실행하고 이유를 기록한다.
- test 점수를 보고 설정·모델·seed를 고르지 않는다. 계산 장치는 노트북 GPU(mps). 스크립트는 이 문서의 sha256을 받아야만 test를 연다.

## 5. 해석할 때 미리 적어 두는 한계

- `test_plan_lung.md` 5장의 한계를 모두 따른다(분할은 항상 맞다는 가정의 필터 시험, test 정상의 분포 차이, 폐 안 흔적·윤곽 모양, seed 3개, 기준 모델 test 점수의 seed 흔들림).
- **폐 분할 오류는 병이 심한 쪽에 몰린다**: train·val·test 5,840장 중 분할 실패 5장은 모두 세균성(train 4, val 1, test 0), 마스크가 쪼개진 사진은 세균성 2.7%·바이러스성 1.3%·정상 0%다. 병변이 껍질 밖으로 잘린 사진은 모델이 볼 단서가 줄어든다.
