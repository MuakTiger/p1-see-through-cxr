# 예방접종 모델(필터 증강) 계획 (결과를 보기 전에 고정)

작성: 2026-10-22 오후, **새 모델의 점수를 보기 전**. 결과를 보고 바꾸지 않는다. 바꿔야 하면 새 버전 문서를 만든다.

## 1. 질문

B512는 조사시간·kVp·센서·산란 필터에 약했다. 학습할 때 기기 설정 필터를 섞어 주면 이 약점이 줄어드는가? 그리고 학습에 쓰지 않은 유형(제조사 후처리, 전송)에서도 덜 무너지는가?

## 2. 설계 (B512에서 증강 하나만 바꿈)

- 공통(B512와 같음): ResNet18 ImageNet 사전학습, layer4 + fc 학습, Adam, 학습률 fc 0.001 / layer4 0.0001, 배치 16, 최대 30에폭, 입력 512, 클래스 가중치 없음, **에폭 선택 규칙도 B512와 같다(원본 val Macro-F1이 가장 높은 에폭)**.
- 증강(`--augment equip`, `training/train_aug.py`): 학습 사진의 **50%**에 기기 설정 필터 5종(선량, 조사시간, 산란, kVp, 센서) 중 **하나를 고르게** 건다. 세기는 사진마다 u ~ Uniform(0, 1)이고, u=0이 원본, **u=1이 시험의 '강'과 같다**(선량 1/64, 번짐 8mm, 산란 k 1.0, kVp (0.60, 0.5), 센서 2.0mm). val(에폭 선택용)에는 증강을 걸지 않는다. 학습 증강과 시험 필터가 같은 코드임을 확인했다(u=1에서 시험 '강'과 완전히 같고 u=0에서 원본과 같음).
- 설계 근거: 장비 물리 사전지식과 val 필터 시험 결과뿐이다. **test 결과에서 얻은 가설(경계 강조가 정상 recall을 올림 등)은 설계에 쓰지 않았다.**
- 비교 대상: 같은 환경(SageMaker JupyterLab, ml.g4dn.xlarge)에서 증강 없이 같은 설정으로 다시 학습한 기준. 예방접종 3개 + 기준 3개 = 6개, seed 42·43·44. 기존 AWS 학습 작업의 B512(seed 42, val 0.843)와도 비교해 환경 차이를 확인한다.

## 3. 평가 (val만, test는 열지 않는다)

`src/equipment_eval_direct.py`와 같은 시험(같은 필터·강도)을 모델마다 한다.

- 원본 val Macro-F1 (원본 성능이 줄지 않았는지).
- 본편 필터 24조건의 평균 Macro-F1을 유형별로 나눈다: **학습에 쓴 유형 5종**(선량, 조사시간, 산란, kVp, 센서)과 **학습에 쓰지 않은 유형 3종**(경계 강조, 대비 보정, JPEG). 흐림·밝게·어둡게는 부록으로 따로 적는다.
- 각 값은 seed 3개의 평균 ± 표준편차로 적고, 예방접종 − 기준의 차이도 적는다.

## 4. 판정 규칙 (미리 정함)

- 차이를 말할 수 있는 기준: 예방접종 − 기준의 평균 차이가 **기준 모델의 seed 표준편차의 2배 이상**일 때만 "차이가 있다"고 쓴다. 아니면 "차이를 말할 수 없다".
- 학습에 쓴 5종은 배운 유형으로 시험한 것이라 방어력의 증거로 쓰지 않고 "배운 유형에서 얼마나 나아졌나"로만 적는다. 학습에 쓰지 않은 3종이 방어력을 보는 부분이다.
- 원본 val F1이 기준보다 seed 표준편차 이상 떨어지면 "원본 성능 손실"로 함께 보고한다.
- 6개 모두의 결과를 빠짐없이 보고한다.

## 5. 한계 (결과와 상관없이 적는다)

- seed 3개라 작은 차이는 구분하지 못한다. 표준편차 추정도 3개에서 나온 것이라 거칠다.
- 학습 세기의 상한이 '강'이라 '강' 안쪽만 본다. 그보다 센 조건은 보지 않았다.
- 학습에 쓰지 않은 유형이 완전히 낯선 것은 아니다. 경계 강조는 선명도, 대비 보정은 대비를 바꾸므로 산란·kVp·센서와 효과 계열이 겹칠 수 있다. 제조사 후처리는 실제 알고리즘이 아니라 대표 기법이다.
- 필터는 실제 장비가 아닌 흉내다. val에서 고른 설정이 test에서도 낫다는 보장이 없다(지금까지 val과 test의 순위가 반대였다).
- 이 실험 뒤에 test를 열면 계획 문서를 새로 만들고, 설계에 test를 참고했는지를 밝힌다.
