## 5. 해석 (위 표의 숫자 기준, 해석 절은 손으로 씀)

1. **C 는 바이러스성 recall 을 조금 올렸다.** B 0.616 → C 0.649 (+0.033, 바이러스성 276장 중 맞힌 수 170 → 179장). 바이러스성을 세균성으로 잘못 본 수가 103 → 93장으로 줄었고, 바이러스성 예측 비율이 23.4% → 25.4% 로 실제 비율 26.8% 에 가까워졌다. 손실 가중치 [정상 1.298, 세균성 0.683, 바이러스성 1.305] 가 의도한 방향(세균성 쏠림 완화)이다.
2. **대가는 세균성 쪽이다.** 세균성 recall 0.852 → 0.840 (416 → 410장), 세균성을 바이러스성으로 본 수 69 → 77장. 정상 recall 0.974 → 0.966, Macro AUROC 0.930 → 0.925 로 약간 내려갔다. Macro-F1 은 0.818 → 0.821 (+0.003) 로 거의 같다.
3. **이 차이는 에폭 간 흔들림보다 작다.** C 의 마지막 5에폭 val Macro-F1 표준편차는 0.017 (0.775~0.821) 이고, 같은 구간 바이러스성 recall 은 0.591~0.768 (표준편차 0.068), 세균성 recall 은 0.684~0.852 (0.079) 로 크게 움직인다. B→C 의 Macro-F1 +0.003, 바이러스성 recall +0.033 은 이 폭 안에 있다. 또 C 의 베스트 에폭은 마지막 에폭(30)이라, 어느 에폭에서 멈추느냐에 따라 숫자가 달라졌을 수 있다. 클래스 가중치가 바이러스성 recall 을 올린다는 결론은 이번 결과만으로는 약하다.
4. **D 와 나란히 보면:** 원본 val 에서 D 는 Macro-F1 0.834, 바이러스성 recall 0.696 으로 C(0.821, 0.649) 보다 높다. 다만 D−C 의 Macro-F1 차이 0.013 도 D(0.011)·C(0.017) 의 마지막 5에폭 표준편차와 비슷한 크기다.
5. **장비 차이 민감도 (Macro-F1):**
   - 노이즈에 B 보다 더 약하다. std 4: C 0.668 (변화 −0.153, 95% [−0.183, −0.122]) vs B 0.765, std 8: C 0.508 vs B 0.646. 노이즈를 넣으면 C 는 바이러스성으로 더 크게 쏠린다 (바이러스성 예측 비율 std 4: B 40% → C 56%, std 8: B 52% → C 69%). 가중치가 바이러스성 쪽에 힘을 실어 준 상태라, B 가 원래 갖던 "노이즈 → 바이러스성" 쏠림이 더 빨리 나타난 것으로 보인다. std 16 에서는 C 0.470 > B 0.363 이지만 둘 다 크게 무너진 상태다. D 는 0.817 (std 8), 0.774 (std 16).
   - JPEG 20 도 C 가 가장 낮다 (C 0.718, B 0.762, D 0.802).
   - 흐림 σ2 (C 0.658, B 0.621, D 0.652) 와 대비 0.55 (C 0.791, B 0.754, D 0.784) 는 C 가 B 보다 덜 떨어졌다. 두 필터는 B 를 세균성으로 쏠리게 하던 조건이라, 세균성 가중치를 낮춘 효과와 방향이 맞는다.
   - 위 95% 구간은 각 모델의 자기 원본 대비 변화다. B·C·D 사이 차이 자체의 구간은 계산하지 않았다.
6. **한계.** 네 실험 모두 seed 1개, 모델 1개씩이다. val 은 베스트 에폭 선택에도 쓰여서 표의 val 점수는 약간 낙관적이다. 클래스 가중치는 영상 수 기준이라, 불균형의 원인인 "세균성 환자 1명당 사진 수"(환자 단위 불균형)는 직접 다루지 않는다. 민감도 시험은 필터로 흉내 낸 조건이며 실제 다른 병원 데이터가 아니다.
