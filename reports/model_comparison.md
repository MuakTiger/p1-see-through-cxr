# 원본 학습(B) 대비 학습 방식을 바꾼 모델 비교

저장된 결과 파일에서 직접 읽어 만들었다 (`src/model_compare.py`). test 는 다시 열지 않았고, 사전에 정한 계획대로 한 번 낸 결과를 그대로 썼다. 모든 값은 Macro-F1 이고 recall 은 그 병인 사진 중 맞힌 비율이다.

**먼저 알아 둘 것:** 밝기·대비를 학습 때 무작위로 바꿔 주는 증강 모델은 만든 적이 없다. 밝기·대비 쪽 변화는 정규화형 전처리 P1(HE)·P2(CLAHE)가 전부이고, '밝게·어둡게·대비 감소'는 학습이 아니라 **시험 조건**으로만 썼다. 노이즈는 D 에서 학습 때 넣었다.

## 4. 한계

- 학습은 대부분 seed 1개다 (D 만 3개). test 는 한 번만 열었고, 그 결과를 보고 설정을 바꾸지 않았다.
- 노이즈 증강과 노이즈 시험은 같은 종류(가우시안)다. 흐림 등 다른 변화에 강해졌다는 뜻이 아니다.
- 장비 차이는 필터로 흉내 낸 것이고, 실제 다른 병원 사진이 아니다.
- A 는 장비 차이 시험을 하지 않았고, B448 은 test 를 열지 않았다. D seed 43·44 도 test 를 열지 않았다.
