# P 시리즈: 전처리별 모델 비교 (val 기준)

- 모든 모델은 실험 B 설정(ResNet18 layer4 미세조정, Adam lr 0.001/0.0001, 배치 16, 30에폭, seed 42, 증강 없음, 클래스 가중치 없음)이고 **입력 전처리 하나만** 다르다. P0 = 실험 B.
- 전처리는 224×224 회색조에서 적용하는 결정적 변환이며 train·val 모두에 똑같이 적용했다 (정의: `training/preprocess.py`).
- 숫자는 val 1,030장 (정상 266 / 세균성 488 / 바이러스성 276) 기준. test 는 쓰지 않았다. '마지막 5에폭'은 에폭 26~30 의 val Macro-F1 (표본 표준편차).
- 민감도 시험 순서: 224 회색조 → 장비 필터(촬영 단계 차이) → 모델의 전처리 → 텐서. 필터 강도는 기존 시험과 같다.
- 표는 `src/preprocess_comparison.py` 가 만들었다. CSV 는 `preprocess_comparison.csv`, 그림은 `preprocess_comparison.png`.

## 4. 해석 (위 표의 숫자 기준, 손으로 씀)

1. **원본 val 점수 차이는 에폭 흔들림 수준이다.** P0 대비 베스트 val Macro-F1 변화는 P1 +0.003, P2 +0.012, P3 −0.001, P4 +0.010 이다. 같은 모델의 마지막 5에폭 표준편차가 0.008~0.015 라서, 가장 큰 차이(P2 +0.012)도 이 폭 안팎이다. 마지막 5에폭 평균으로 보면 순서가 바뀐다 (P4 0.818 > P1 0.809 > P2 0.806 > P0 0.802 > P3 0.797). 원본 점수만으로 "이 전처리가 더 낫다" 고 말하기는 어렵다.
2. **차이는 장비 차이 시험에서 크게 났다.** 전처리마다 강해진 조건과 약해진 조건이 뚜렷하게 갈렸다.
   - **P1 HE: 밝기·대비 변화를 거의 지운다.** 밝게 γ0.55, 어둡게 γ1.8, 대비 0.55, 대비 보정(HE) 에서 변화가 −0.002~+0.001 이고 95% 구간이 모두 0 을 포함한다 (P0 은 −0.027~−0.064). 감마·대비 조절은 밝기 순서를 바꾸지 않는 변환이라 HE 를 거치면 거의 같은 사진이 되기 때문으로 보인다 (모델이 배운 것이라기보다 전처리가 차이를 지운 것). 흐림 σ2 도 0.747 로 P0(0.621)보다 덜 떨어졌다. 대신 경계 강조 α2 (0.750, P0 0.798), JPEG 20 (0.732, P0 0.762) 에는 더 약하고, 노이즈는 P0 와 비슷하게 약하다 (std 8: 0.649).
   - **P2 CLAHE: 어둡게·대비 보정에는 강하지만 노이즈와 압축에 가장 약하다.** 어둡게 γ1.8 −0.006, 대비 보정(HE) −0.009 (구간이 0 포함). 밝게 γ0.55 (−0.028) 와 대비 0.55 (−0.047) 는 P0 와 비슷하게 떨어져서, 밝기·대비 변화 전반에 HE 만큼 강하지는 않다. 노이즈는 std 4 에서 이미 0.547 (P0 0.765), std 8 0.277, std 16 0.148 로 무너지고, 예측이 바이러스성으로 쏠린다 (바이러스성 예측 비율 원본 31% → std 4 70% → std 8 91% → std 16 100%). JPEG 20 도 0.563 (바이러스성 예측 67%). CLAHE 가 구역마다 대비를 키우면서 노이즈·압축 무늬도 함께 키운 것으로 보이며, "미세 무늬가 늘면 바이러스성으로 쏠린다" 는 기존 관찰(B, C)과 방향이 같다.
   - **P3 LPF: 노이즈·흐림·압축에 가장 강하다.** 노이즈 std 4 −0.004 (구간 0 포함), std 8 0.790, std 16 0.689 (P0 0.646, 0.363). 흐림 σ2 0.788 (변화 −0.030, P0 −0.197), JPEG 20 0.794. 24개 조건 평균 0.799 로 P0~P4 중 가장 높다. 모델 전처리의 가우시안이 들어온 노이즈·압축 무늬를 먼저 지우고, 학습 때부터 흐린 사진을 봤기 때문으로 보인다. 대신 원본 점수는 P0 와 같고(0.818), 밝게 γ0.55 (−0.033) 와 대비 0.55 (−0.047) 는 P0 와 비슷하게 떨어진다.
   - **P4 HPF: 노이즈와 경계 강조에 P0 보다 약하다.** 노이즈 std 4 0.644 (P0 0.765), std 8 0.532 이고, 이때 세균성 recall 이 원본 0.834 → std 4 0.30 → std 8 0.08 로 떨어지며 바이러스성으로 쏠린다 (바이러스성 예측 26% → 59% → 71%). 경계 강조 α2 0.746 (−0.082). 학습 입력에 이미 언샤프를 걸어서, 추가 경계 강조와 노이즈가 언샤프를 거치며 더 커지는 것으로 보인다. 어둡게 γ1.8 (0.000) 에는 강하다.
3. **바이러스성 recall 은 네 전처리 모두 P0 보다 높다.** P0 0.616 (276장 중 170장) → P1 0.674, P2 0.750 (207장), P3 0.707, P4 0.667. 대신 세균성 recall 이 P0 0.852 → P1 0.822, P2 0.797 (488장 중 416 → 389장), P3 0.781, P4 0.834 로 내려갔고, 바이러스성 예측 비율이 23.4% → 25.6~30.6% 로 늘었다. 세균/바이러스 경계가 바이러스성 쪽으로 옮겨 간 효과가 크고, 두 클래스를 더 잘 가르게 됐다고 보기는 어렵다 (Macro AUROC 0.924~0.933 로 P0 0.930 과 비슷).
4. **D(노이즈 증강)와 나란히 보면:** D 는 원본 0.834, 24개 조건 평균 0.806, 노이즈 16 0.774 로 노이즈에는 P3 보다 강하지만, 흐림 σ2 는 0.652 로 P3(0.788)·P1(0.747) 보다 약하다. 전처리(P3)와 증강(D)이 강한 조건이 서로 다르다. 두 방법을 함께 쓴 모델은 만들지 않았다.
5. **한계.** 모델마다 seed 42 로 한 번씩만 학습했다. val 은 베스트 에폭 선택에도 쓰여서 표의 val 점수는 약간 낙관적이다. 민감도 시험은 고전 필터로 흉내 낸 장비 차이이며 실제 다른 병원 데이터가 아니다. 전처리 모델의 강점 일부는 "모델이 강해진 것" 이 아니라 "전처리가 필터 효과를 지운 것" 이다 (P1 의 밝기·대비, P3 의 노이즈). 위 95% 구간은 각 모델의 자기 원본 대비 변화이며, 모델끼리의 차이 자체의 구간은 계산하지 않았다. LFR(폐 영역 집중도)은 Grad-CAM 단계에서 잴 예정이라 아직 비어 있다.
