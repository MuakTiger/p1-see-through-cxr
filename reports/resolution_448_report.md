# 입력 해상도 224 → 448 실험 (모델 B448)

질문: 사진을 224 대신 448로 줄여서 넣으면 (강사 의견) 점수, 장비 차이 버팀, Grad-CAM 이 달라지는가.
설정: 모델 B 와 똑같고 입력 크기만 448 (layer4+fc 학습, Adam, 배치 16, 30에폭, seed 42, 증강 없음, val Macro-F1 로 에폭 선택).
AWS `ml.g4dn.2xlarge` 1건, 학습 982초. **test 는 열지 않았다.** 단일 seed.

## 1. val 성능

| 모델 | 입력 | 선택 에폭 | val Macro-F1 | val AUROC | 정상 recall | 세균성 recall | 바이러스성 recall |
|---|---|---|---|---|---|---|---|
| B | 224 | 21 | 0.818 | 0.930 | 0.974 | 0.852 | 0.616 |
| D | 224 | 26 | 0.834 | 0.931 | 0.981 | 0.826 | 0.696 |
| B448 | 448 | 12 | 0.830 | 0.928 | 0.966 | 0.844 | 0.670 |

B 대비 +0.012 는 seed 1개의 흔들림 범위로 보인다. 에폭별 val F1 곡선도 B 와 거의 겹친다. 해상도로 점수가 올랐다고 말할 근거는 약하다.

## 2. 장비 차이 시험 (val, 8종 × 3단계 = 24조건, Macro-F1)

필터의 σ(블러, 샤프닝)는 입력 크기 비례로 키워서 같은 해부학적 크기에 적용했다 (노이즈 std, 감마, 대비, JPEG 품질은 그대로).

## 4. Grad-CAM 14×14 vs 7×7 (val, `reports/gradcam_resolution/`, `src/gradcam_resolution.py`)

| | B 224 (7×7) | B448 (14×14) |
|---|---|---|
| 활성 면적 (지도 ≥ 0.5 인 픽셀 비율) | 0.271 | **0.116** |
| 흉부 상자 안 비율 | **0.623** | 0.521 |
| 테두리 띠 비율 | **0.413** | 0.534 |
| 원본↔노이즈 지도 상관 (평균) | 0.279 | 0.309 |

(참고: D 의 원본↔노이즈 상관은 0.644, `reports/gradcam/gradcam_report.md`.) B224 값은 기존 보고서와 일치했다.
두 모델이 같은 사진에서 낸 지도의 상관은 평균 0.249 로 서로 다른 곳을 본다.

- 지도는 더 세밀해졌다 (활성 면적이 절반 이하). 그러나 상자 근사 기준으로는 폐 안쪽을 더 잘 짚지 않고 테두리(어깨, 쇄골, 모서리) 쪽 비율이 오히려 늘었다. 예시 그림 `gradcam_resolution_examples.png` 에서도 어깨나 위 모서리에 붉은 점이 자주 찍힌다.
- 노이즈에서 지도가 유지되는 정도는 B 와 비슷하게 낮다 (0.31 대 0.28).
- 한계: 병변 표시가 없어서 지도의 "정확도"는 잴 수 없다. 여기서 잰 것은 세밀함과 안정성이다. 폐 마스크가 없어 "상자 안"은 근사다. 단일 seed.

## 결론

- 해상도 448 은 val 원본 점수를 올리지 못했고 (0.818 → 0.830, 흔들림 수준), 장비 차이에는 오히려 약했다 (24조건 평균 0.767 → 0.743).
- 저장 화질 지름길은 448 에서도 쓰지 않는다.
- 열지도는 세밀해졌지만 폐를 더 잘 가리키지는 않는다.
- 최종 모델은 D (224) 를 유지한다. 448 은 사후 비교 실험으로만 보고한다. B448 의 test 평가는 하지 않았다 (하면 test 두 번째 사용).
