# 장비 차이 민감도 시험: 필터 선택과 강도의 근거

## 1. 왜 이 시험을 하는가

이 데이터(Kermany 2018)는 중국 광저우 여성아동의료센터 한 곳에서 찍은 소아 흉부 X선이다. 학습과 평가가 모두 같은 병원 장비의 사진이라, test 점수가 높아도 다른 병원 장비에서 같은 성능이 나온다는 보장이 없다.

실제로 Zech 등(2018, PLOS Medicine)은 미국 병원 시스템 세 곳의 흉부 X선으로 폐렴 CNN을 시험했다. 다섯 번의 비교 가운데 세 번에서 외부 병원 사진에 대한 성능이 원래 병원보다 유의하게 낮았다. CNN은 사진만 보고 촬영한 병원과 부서를 매우 높은 정확도로 알아냈다. [1][2]

다른 병원 데이터는 없으므로, 장비마다 달라지는 사진 특성을 고전 영상처리 필터로 흉내 낸다. 그리고 학습된 모델이 그 변화에 얼마나 민감한지 잰다.

## 2. 장비 차이의 원인과 필터 대응

| 실제 원인 | 사진에서 달라지는 것 | 필터 | 강도 (약 / 중 / 강) |
|---|---|---|---|
| 검출기 해상도 차이(CR 판 vs DR 평판), 환자 움직임 | 미세한 무늬가 흐려짐 | 흐림 (가우시안 LPF), σ | 0.5 / 1.0 / 2.0 px |
| 제조사의 자동 경계 강조 후처리 | 경계와 미세 무늬가 날카로워짐 | 경계 강조 (언샤프 HPF), α, σ=2 | 0.5 / 1.0 / 2.0 |
| 저선량 촬영 (소아는 선량을 낮춤) | 지글거리는 양자 노이즈 | 가우시안 노이즈, 표준편차 (0~255) | 4 / 8 / 16 |
| 과다 노출, 밝게 맞춘 표시 설정 | 중간 밝기가 밝아짐 | 감마 < 1 | 0.85 / 0.7 / 0.55 |
| 노출 부족, 어둡게 맞춘 표시 설정 | 중간 밝기가 어두워짐 | 감마 > 1 | 1.2 / 1.45 / 1.8 |
| 산란선 차단 격자 없이 촬영, 창 설정 차이 | 사진이 뿌옇고 대비가 낮음 | 평균 중심 대비 축소, 배율 | 0.85 / 0.7 / 0.55 |
| 제조사·병원마다 다른 자동 대비 보정 | 구역마다 밝기 분포가 재배치됨 | CLAHE(8×8) / 전역 HE | clip 1.5 / clip 3.0 / HE |
| PACS 밖으로 내보내기, 메신저 전송, 재압축 | 8×8 블록 무늬, 미세 무늬 손실 | JPEG 재압축, 품질 | 75 / 40 / 20 |

크기 감각: 모든 필터는 224×224 회색조에서 적용한다. 224 픽셀이 가슴 폭 약 20cm에 해당하므로, 1픽셀은 약 1mm다. 원본 크기가 384~2916 픽셀로 제각각이라, 같은 크기로 줄인 뒤 적용해야 같은 강도가 모든 사진에서 같은 의미를 가진다.

## 3. 강도를 정한 원칙

- 단계는 약·중·강 셋으로 둔다. "강"은 질이 나쁜 장비나 촬영에서 있을 법한 상한이다. 현실 범위 밖의 극단값(1차 갤러리의 JPEG 품질 5, 대비 0.3, 흐림 σ 4, 노이즈 30)은 뺐다.
- 강도는 갤러리를 눈으로 보고 시험 전에 고정했다. 시험 점수를 보고 바꾸지 않는다.
- 밝기는 원인이 반대인 두 방향(과다·부족 노출)을 따로 시험한다.
- 이 수치들은 특정 장비의 실측값이 아니라, 원인별 변화 방향과 대략의 크기를 반영한 설정이다.

## 4. 흉내 내지 못하는 것 (한계)

- 촬영 자세와 모양 차이: 서서 찍기(PA)와 누워서 찍기(AP, 휴대용 장비), 확대 비율, 회전, 촬영 범위.
- 화면 속 글자와 표식: 병원마다 "R", "A-P" 같은 표식의 위치와 글꼴이 다르다. 모델이 표식에 의존하는지는 Grad-CAM과 폐 영역 집중도(LFR)로 따로 확인한다.
- 환자 집단 차이: 나이, 질병 비율, 중증도. Zech 등이 보고한 꼼수(병원별 유병률에 맞춘 예측)는 이 시험으로 재현할 수 없다.
- 노이즈 모양: 실제 양자 노이즈는 밝기에 따라 크기가 달라지지만, 여기서는 고른 가우시안으로 단순화했다.
- 원본 비트 깊이: 공개 데이터는 이미 8비트 JPEG라, 원본 DICOM(12~16비트)에서 생기는 차이는 볼 수 없다.

따라서 이 시험은 "다른 병원에서의 성능"을 증명하지 않는다. 사진 질감과 밝기 차이에 대한 **민감도**만 보여 준다.
