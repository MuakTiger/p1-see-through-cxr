## 해석 (숫자는 위 표 기준)

0. **원본 점수:** D 0.834, B 0.818 (+0.016). 바이러스성 recall은 0.696 vs 0.616, 정상 0.981 vs 0.974, 세균성 0.826 vs 0.852. 노이즈 증강이 원본 성능을 깎지는 않았다. 다만 +0.016은 D의 에폭별 흔들림(21~30에폭 0.782~0.834) 안에 있는 크기라, 원본 점수가 좋아졌다고 말할 근거는 약하다.
1. **(a) 노이즈 저항은 뚜렷하게 좋아졌다.** std 4에서 변화가 B −0.054 → D −0.016, std 8에서 B −0.172 → D −0.017. D는 두 강도 모두 95% 구간이 0을 포함한다. B에서 보이던 바이러스성 쏠림(바이러스성 예측 23% → 40% → 52%)이 D에서는 27% → 29% → 28%로 거의 없다. B의 세균성 recall은 0.852 → 0.381(std 8)로 무너졌지만 D는 0.826 → 0.816이다.
2. **(b) 학습 범위 밖 std 16에서도 차이가 크다.** B 0.363(−0.455) → D 0.774(−0.060, 95% [−0.084, −0.037]). 바이러스성 예측 비율은 B 82%, D 33%. 학습하지 않은 세기에서도 무너지지 않았지만, D도 이 강도에서는 0이 아닌 하락이 남는다.
3. **(c) 다른 필터에는 효과가 섞여 있다.**
   - 흐림 σ 2: 하락 크기는 비슷하다 (B −0.197, D −0.182). 정상 recall이 두 모델 모두 0.5 안팎으로 떨어진다. 다만 쏠리는 방향이 바뀌었다: B는 세균성 +14%p, D는 바이러스성 +11%p. 노이즈 증강은 흐림 문제를 풀지 못했다.
   - 대비 감소 0.55: B −0.064, D −0.050로 비슷하다. B의 세균성 쏠림(+9%p, 바이러스성 recall 0.413)은 D에서 사라졌다(바이러스성 recall 0.609).
   - 어둡게 γ 1.8: B −0.027 → D +0.007 (구간이 0 포함). JPEG 20: B −0.057 → D −0.032.
   - **나빠진 곳:** 경계 강조. α 1.0에서 B −0.004 → D −0.034, α 2.0에서 B −0.021 → D −0.050 (D는 두 강도 모두 구간이 0을 포함하지 않음). D는 경계 강조에서 바이러스성 recall이 0.696 → 0.489로 떨어지고 세균성으로 기운다. 밝게 γ 0.55도 B −0.028 → D −0.039로 약간 더 떨어진다.
   - 정리하면 노이즈 증강은 "노이즈에 대한 둔감함"을 얻은 대신 일부 다른 질감 변화(경계 강조)에는 더 민감해졌다. 모든 장비 차이에 강해진 것이 아니다.
4. **(d) 한계.**
   - 단일 seed, 모델 하나씩이다. seed를 바꾸면 B와 D 모두 숫자가 달라질 수 있다.
   - val은 두 모델의 에폭 선택에도 쓰였다. 원본 점수는 약간 낙관적이다.
   - 위 95% 구간은 각 모델의 "자기 원본 대비 변화"에 대한 것이다. B와 D의 차이(D−B) 자체에 대한 구간은 계산하지 않았다. 노이즈 std 8·16처럼 차이가 매우 큰 경우가 아니면 D−B 차이는 우연일 수 있다.
   - 학습 증강과 시험 필터가 같은 종류(고른 가우시안 노이즈)다. 실제 저선량 노이즈는 밝기마다 크기가 다르므로, 실제 장비 노이즈에서도 같은 효과가 난다는 보장은 없다.
   - 흉내 낸 조건이다. 다른 병원 데이터에서의 성능을 증명하지 않는다.
