## 3. 전처리

학습과 똑같은 P0: `convert("RGB")` → `Resize((224,224))` → `ToTensor` → `Normalize(ImageNet mean/std)`. 증강 없음.

## 4. 지표 (주 평가 세트 618장)

- 주 지표: **Macro-F1**
- 함께 보고: 클래스별 Precision / Recall / F1, 클래스별 AUROC와 Macro AUROC, 정확도(단독 지표로 쓰지 않음), 혼동행렬(행 = 실제, 열 = 예측), 클래스별 영상 수와 환자 수.
- 예측 규칙: 확률이 가장 큰 클래스 (임계값 조정 없음).
- 신뢰구간: 환자 그룹(patient_group) 단위 bootstrap 2,000회, seed 42, 95% 백분위 구간 (가이드 12장). test 세균성은 환자 77명에 사진 242장이라 사진 단위 구간은 너무 좁게 나온다.
- 정밀도 분모가 0이면 F1 = 0으로 처리하고 따로 기록한다.

## 5. 보조 분석 (보고만 하고, 선택에는 쓰지 않음)

1. 624장 전체에서의 같은 지표.
2. 원래 train과 같은 personN 번호를 가진 test 사진(약 320장)과 나머지 사진의 Macro-F1 비교. 번호가 같아도 같은 환자가 아니라는 판단의 간접 확인용이다. 점수 차이가 크면 한계로 기록한다.
3. 다른 모델(A, B, C, P1~P4)의 test 점수. val 순위가 test에서도 유지되는지 보는 참고용이다. 최종 모델은 D로 이미 고정했으므로 바꾸지 않는다.
4. 오분류 목록: 정상→폐렴, 폐렴→정상, 세균성↔바이러스성으로 나눠서 확률과 함께 기록한다 (Grad-CAM 단계에서 사용).
